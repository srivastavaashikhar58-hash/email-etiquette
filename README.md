# Email Etiquette & Professional Writing

A fully responsive, interactive **web presentation** built from the *Email Etiquette & Professional Writing* slide deck by **MR Tejas Jaiswal** (BCA FSD, 1st Year).

## 🌐 Live Demo
*(Deploy to GitHub Pages to get a live URL — see below)*

## 📂 Project Structure

```
email-etiquette/
├── index.html   – Semantic HTML with 10 content sections
├── style.css    – Modern CSS with custom properties, animations
├── script.js    – Scroll-in effects, interactive checklist, nav highlight
└── README.md    – This file
```

## ✨ Features

| Feature | Detail |
|---|---|
| **10 slide sections** | All content from the original PPTX |
| **Responsive layout** | Works on mobile, tablet and desktop |
| **Smooth scroll** | Animated section reveal on scroll |
| **Interactive checklist** | Tick off pre-send items (slide 9) |
| **Active nav dots** | Side navigation highlights current section |
| **Zero dependencies** | Pure HTML + CSS + vanilla JS |

## 🚀 Deploy to GitHub Pages

1. Push this repository to GitHub (already done).
2. Go to **Settings → Pages**.
3. Set source to **main branch / root**.
4. Your site will be live at `https://<your-username>.github.io/email-etiquette/`.
